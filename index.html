03 — SECURITY MODEL

Ваши ключи.
Ваше устройство.

TON Username не видит сид-фразу и не умеет её восстановить. Генерация проходит в памяти вкладки с помощью Web Crypto API.

01Без серверовЗапросы к API не нужны для генерации.
02Без аналитикиМы не собираем события и не ставим трекеры.
03Open sourceКод можно проверить и запустить самостоятельно.
